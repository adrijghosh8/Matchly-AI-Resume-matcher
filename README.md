# Matchly — AI Resume Matcher

> **Match your resume with the right opportunity.**

Matchly is an **AI-powered resume–job matching system** that uses **NLP, TF-IDF, and skill-based matching** to measure how well a resume fits a job role and identify missing skills.

## ✨ Features

* 📄 **Resume Analysis** — Extracts and processes resume content
* 🎯 **Job Matching** — Calculates resume–job compatibility
* 🧠 **Skill Matching** — Compares candidate skills with required skills
* 📊 **TF-IDF Similarity** — Measures textual similarity between resume and job description
* 🔍 **Skill Gap Analysis** — Highlights missing or unmatched skills
* 💼 **Job Role Selection** — Supports predefined job roles and relevant skills

## 🛠️ Tech Stack

**Python** • **NLP** • **Scikit-learn** • **TF-IDF** • **HTML** • **CSS** • **JavaScript**

## ⚙️ How It Works

```text
Resume
   ↓
Text Extraction & Preprocessing
   ↓
Skill Extraction ──────┐
                       ↓
Job Description → TF-IDF Similarity
                       ↓
              Combined Match Score
                       ↓
             Skill Gap Analysis
```
